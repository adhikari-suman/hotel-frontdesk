Front desk · 10 designs

Ten different visual directions for the same hotel front-desk app. Each one covers all 9 screens with identical content, so you compare the design, not the data: Today, Availability, New booking, Booking detail + rebook, Check in, Check out, Rooms, Promo codes and Users. Every direction was derived from its own random seed string.

1440 px desktop screens, exported as PNG @2x. Each design folder holds its HTML, assets, PNGs and a README with tokens. All guest data, prices, the 12% tax and the promo "Offer" field are placeholders, not spec.
