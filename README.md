# Hotel front desk

Design exploration for a single-hotel front-desk web app. There are two roles:
- **Receptionist:** book, rebook, check in, check out, cancel, add extras (breakfast, dinner, arrival pickup), and apply promo codes.
- **Admin:** manage users and rooms, and create promo codes.

There are 15 visual directions, and each has the same 9 desktop screens built from the same synthetic data. To compare them screen by screen, open [`designs/index.html`](designs/index.html) locally. For the screen list, folder layout and open decisions, see [`designs/README.md`](designs/README.md).

| # | Direction | In one line |
|---|---|---|
| 1 | **[Transit Map](designs/design-1/)** | Room types are coloured lines; each stay is a journey from an arrival stop to a departure stop. The nav is a route map with a locked admin branch |
| 2 | **[Split-Flap](designs/design-2/)** | A station concourse: arrivals and departures on split-flap boards, and screens are stops on one route line |
| 3 | **[Switchboard](designs/design-3/)** | Rooms are jacks with lamps, a booking is a patch cord and the folio is a toll ticket. Lever keys run along the bottom |
| 4 | **[Fob Rack](designs/design-4/)** | The pigeonhole wall behind the counter: a hanging key fob means the key is at the desk |
| 5 | **[Drawing Set](designs/design-5/)** | Architect's sheets: a floor plan with door swings, stays as dimension lines and warnings as revision clouds. A title-block sheet index is the nav |
| 6 | **[Mountain & Valley](designs/design-6/)** | Folded paper: each room's fold shows its state. Screens are tri-folds and the nav is folder tabs |
| 7 | **[Counting Frame](designs/design-7/)** | A soroban: each room is a rod with one bead, raised when occupied and halfway when arriving |
| 8 | **[Elements](designs/design-8/)** | The hotel as a periodic table: rooms are element tiles with two-letter status symbols |
| 9 | **[Lit Windows](designs/design-9/)** | The hotel from the street at dusk: every room is a window. The nav is a lift panel with an admin key switch |
| 10 | **[Stamp Sheet](designs/design-10/)** | Perforated room stamps, engraved prices and out-of-order overprints. A booking is a franked airmail cover |
| 11 | **[Warp & Weft](designs/design-11/)** | Cloth on a loom: stays are woven across nights, and status is a weave pattern plus a glyph and a word |
| 12 | **[House Lights](designs/design-12/)** | A theatre box office after dark (the only dark UI): rooms are seats and stays are tickets. Footlights are the nav |
| 13 | **[Tide Table](designs/design-13/)** | A hydrographic chart: occupancy is a tide curve and statuses are buoys, each with its own shape |
| 14 | **[Lift Car](designs/design-14/)** | A 1930s lift: the nav is a brass floor dial, with admin floors past a key switch |
| 15 | **[Leadlight](designs/design-15/)** | An Arts & Crafts leaded window: rooms are glass panes, and a 3 × 3 window is the nav |
